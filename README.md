## TrenTorch

Learn machine learning by building it from first principles.

TrenTorch is an open-source learning platform designed to help developers understand machine learning, deep learning, inference, and GPU computing through hands-on implementations and coding challenges.

Instead of only learning theory or relying on existing frameworks, you build the underlying components yourself, solve practical problems, and develop a deeper understanding of how modern ML systems work.
